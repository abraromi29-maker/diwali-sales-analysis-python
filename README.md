# 🎇 Diwali Sales Analysis

## 📌 Project Overview
This project is an Exploratory Data Analysis (EDA) of Diwali sales data. The goal is to understand customer purchasing behavior and extract meaningful business insights.

## 📊 Key Insights
- Gender-wise purchasing trends
- Age group contribution in sales
- Top performing states
- High revenue product categories
- Customer occupation analysis

## 🛠️ Tools & Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📁 Dataset Description
The dataset contains customer purchase details during the Diwali festival season including:
- Customer demographics
- Product categories
- Purchase amount
- State and occupation data

## 📈 Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Visualization using Seaborn & Matplotlib
4. Business Insight Extraction

## 📌 Key Visualizations
- Gender vs Purchase Amount
- State-wise Sales Analysis
- Occupation vs Spending
- Age Group Analysis
- Product Category Performance

## 🚀 Future Improvements
